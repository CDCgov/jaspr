About JASPR

JASPR is a curve-fitting and report-generation application for antigenic assay analysis used in viral surveillance workflows. Supported workflows include high content imaging-based neutralization test (HINT) (Gubareva et al., 2019), Infected Cell Population (ICP) (Gubareva et al., 2019), and Focus Reduction Neutralization Test (FRNT) (Suthar et al., 2020).

The analysis begins with loading assay inputs on the Load Data page (parser + data file + key file), then reviewing curves and tables on the Analysis page, and generating outputs on the Report page. Before uploading the next dataset, select Reset Session to clear current data and selections. Optional setting adjustments can be made on the Settings page when fit tuning is desired.

New users can download bundled sample files from the Example Data section to get started.

Instructions for Use

  1. Open Load Data, select the parser for your assay/instrument, upload the data file and key file, then click Submit.
  2. Open Analysis to review curves and tables for the loaded data.
    • Analysis and Report pages appear in the navigation menu only after data is loaded into the active session.
    • The Virus and Serum samples displayed in the graph are indicated in the upper left.
  3. Open Report to generate and download valid outputs for the loaded run.
  4. Click Reset Session before uploading the next dataset to clear current data and selections.

Optional: Use Settings to adjust fit visibility, blank correction, axis scale, and fitting function, then click Execute to apply updates and re-check Analysis/Report outputs.

  • HINT (high content imaging-based neutralization test): Supports antigenic workflows including ICP-informed working virus dilution.
    Default settings:
    • Show Curve Fit: On
    • Blank Correction: On
    • X-axis: Log
    • Fit Function: robust_logistic4
    Reference publication: Gubareva et al., 2019.
  • ICP (Infected Cell Population): Supports serial virus dilution workflows to estimate the dilution where ICP reaches 1000, which is then used in HINT setup.
    Default settings:
    • Show Curve Fit: On
    • Blank Correction: On
    • X-axis: Log
    • Fit Function: ICP_robust_logistic3
    Reference publication: Gubareva et al., 2019.
  • FRNT (Focus Reduction Neutralization Test): Supports FRNT assay data processing and report outputs.
    Default settings by parser:
    • FRNT Virus-Serum-Serum Plate Layout Cx5: Show Curve Fit = On, Blank Correction = Off, X-axis = Log, Fit Function = logistic4
    • FRNT Serum-Virus-Virus Plate Layout Cx5: Show Curve Fit = On, Blank Correction = Off, X-axis = Log, Fit Function = logistic4
    • FRNT Virus-Serum-Serum Plate Layout Cytation7: Show Curve Fit = On, Blank Correction = Off, X-axis = Log, Fit Function = logistic4

Current setting values and calculated results are shown in the upper-left of the chart view.

Use the Settings page to tune fit behavior, then click Execute to apply changes and refresh Analysis and Report outputs.

Setting Controls
  • Show Curve Fit: Toggles fit-line visibility on analysis charts; disable to inspect only measured data points.
  • Blank Correction: Uses blank/background correction (y_corrected) instead of raw y_values when computing fits and derived labels.
  • Axis Scale: Switches concentration axis between Log and Linear; this affects fit/plot x-series used in charts.
  • Fit Function: Selects the curve model used to compute result labels (for example titer, IC50, ec50, or ICP1000).
  • Execute: Applies all setting changes to the active session and returns to Analysis for immediate review.
How Curve Fitting Works (Math/Statistics Translation)

JASPR fits models using scipy.optimize.least_squares. For every model, it computes residual = observed y - predicted y at each concentration and then minimizes the residual vector. The optimizer tries multiple starting guesses and keeps the first successful convergence.

Loss function translation: loss='linear' means ordinary least squares (L2), and loss='soft_l1' means a robust loss that reduces the influence of outliers.

Fit Implementations Translated to English
  • linear (loss='linear'): Fits a straight line, y = slope*x + intercept, by ordinary least squares. Default for anscombe; available for all parsers.
  • robust_linear (loss='soft_l1'): Fits the same straight line, but down-weights outliers using a robust loss. Available for all parsers.
  • logistic3 (loss='linear'): Fits a 3-parameter logistic/saturation curve with Vmax and Ki (IC50). Available for all parsers.
  • robust_logistic3 (loss='soft_l1'): Fits the same 3-parameter logistic shape with robust outlier handling. Available for all parsers.
  • ICP_logistic3 (loss='linear'): Fits the ICP-oriented 3-parameter logistic form used for ICP1000 calculation. Recommended for ICP analyses only (available in Settings but generally not appropriate for non-ICP parser data).
  • ICP_robust_logistic3 (loss='soft_l1'): Robust ICP-oriented 3-parameter logistic used to derive ICP1000. Default for ICP celigo.
  • logistic4 (loss='linear'): Fits a 4-parameter logistic curve with a free Hill slope h, often used for titer/ec50 reporting. Default for FRNT parsers; available for all parsers.
  • robust_logistic4 (loss='soft_l1'): Fits the same 4-parameter logistic curve with robust outlier resistance. Default for HINT celigo; available for all parsers.
  • logistic4_h=1 (loss='linear'): Fits a 4-parameter logistic curve with Hill slope fixed at 1. Available for all parsers.
  • robust_log4_h=1 (loss='soft_l1'): Robust version of the fixed-Hill logistic model. Available for all parsers.

The Report page is hidden until data is loaded. After loading, it shows only the report exports that are expected to work for that analysis type.

  • Antigenic assays: Antigenic and Result Analysis exports are shown when required result fields are present.
  • ICP assays: ICP 1000 export is shown only when ICP1000 values are available from the active fit results.

If a report link is not shown, that export is not supported for the currently loaded analysis/session.
