About JASPR

JASPR is a curve-fitting and report-generation application for antiviral assay analysis used in influenza surveillance workflows. It supports common 96-well plate workflows and helps teams move from instrument output to interpretable titers and quality flags quickly.

This deployment includes parser support for HINT, ICP, and FRNT assays, in addition to the built-in Anscombe demonstration dataset. Use the Load Data page to choose a parser and import matching data and key files.

Instructions for Use

  1. Open Load Data, select the parser matching your assay and instrument.
  2. Upload the assay data file and matching key file, then click Submit.
  3. Review curves and tables on this page, then generate exports from the Reports tab.
Parser Notes
  • HINT: Supports antigenic HINT workflows including ICP-informed working virus dilution. Reference publication: Nature Scientific Reports (2019).
  • ICP: Supports serial virus dilution workflows to estimate the dilution where ICP reaches 1000, which is then used in HINT setup.
  • FRNT: Supports FRNT assay data processing and report outputs. Reference protocol: Current Protocols FRNT method.
