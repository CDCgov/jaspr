About JASPR

JASPR is a curve-fitting and report-generation application for antiviral assay analysis used in influenza surveillance workflows. A complete run starts by entering assay inputs on the Load Data page (data file + key file + parser), followed by automated parsing, curve fitting, and result generation.

After analysis, use the main review page to inspect experiment-level curves and tables, optionally tune fit behavior on the Settings page, then export final outputs from the Reports page. The Reset Session control clears the active run so you can begin a clean analysis, and the License page provides parser-specific guidance, references, and operating notes.

Instructions for Use

  1. Open Load Data, select the parser matching your assay and instrument, upload the assay data and key files, then click Submit.
  2. Analysis appears in the navigation menu only after data is loaded into the active session.
  3. Use the main analysis/review page to inspect the loaded run by experiment and sample, including fitted curves and data tables.
  4. Open Reports to generate and download assay output tables and report files for the current session.
  5. Open Settings to adjust analysis options (fit visibility, blank correction, axis scale, and fitting function), then return to review/report pages to verify updated outputs.
  6. Use Reset Session when starting a new run so prior data and selections do not carry into the next analysis.
  7. Open License for parser documentation, reference materials, and assay-specific instructions.
Parser Notes
  • HINT: Supports antigenic HINT workflows including ICP-informed working virus dilution.
    Default settings:
    • Show Curve Fit: On
    • Blank Correction: On
    • X-axis: Log
    • Fit Function: robust_logistic4
    Reference publication: Nature Scientific Reports (2019).
  • ICP: Supports serial virus dilution workflows to estimate the dilution where ICP reaches 1000, which is then used in HINT setup.
    Default settings:
    • Show Curve Fit: On
    • Blank Correction: On
    • X-axis: Log
    • Fit Function: ICP_robust_logistic3
  • FRNT: Supports FRNT assay data processing and report outputs.
    Default settings:
    • Show Curve Fit: On
    • X-axis: Log
    • Fit Function: logistic4 (V-S-S layouts) or robust_logistic4 (parser-dependent)
    • Blank Correction: parser-dependent; Off for V-S-S Cx5 layouts
    Reference protocol: Current Protocols FRNT method.
Supported Instruments
  • HINT:
    • Celigo
  • ICP:
    • Celigo
  • FRNT:
    • Cx5
    • Cytation7

To update settings and re-analyze data: open Settings, change the fit controls, then return to the review or report pages. JASPR applies the updated session settings to subsequent chart/table generation and report exports.
