About JASPR

JASPR is a curve-fitting and report-generation application for antiviral assay analysis used in influenza surveillance workflows. A complete run starts by entering assay inputs on the Load Data page (data file + key file + parser), followed by automated parsing, curve fitting, and result generation.

After analysis, use the main review page to inspect experiment-level curves and tables, optionally tune fit behavior on the Settings page, then export final outputs from the Reports page. The Reset Session control clears the active run so you can begin a clean analysis, and the License page provides parser-specific guidance, references, and operating notes.

Instructions for Use

  1. Open Load Data, select the parser matching your assay and instrument, upload the assay data and key files, then click Submit.
  2. Analysis appears in the navigation menu only after data is loaded into the active session.
  3. Report appears in the navigation menu only after data is loaded into the active session.
  4. Use the main analysis/review page to inspect the loaded run by experiment and sample, including fitted curves and data tables.
  5. Open Report to generate and download only the exports that are valid for the currently loaded analysis.
  6. Open Settings to adjust analysis options (fit visibility, blank correction, axis scale, and fitting function), then click Execute to apply changes and return to Analysis for verification.
  7. Use Reset Session when starting a new run so prior data and selections do not carry into the next analysis.
  8. Open License for parser documentation, reference materials, and assay-specific instructions.
Parser Notes
  • HINT: Supports antigenic HINT workflows including ICP-informed working virus dilution.
    Default settings:
    • Show Curve Fit: On
    • Blank Correction: On
    • X-axis: Log
    • Fit Function: robust_logistic4
    Reference publication: Nature Scientific Reports (2019).
  • ICP: Supports serial virus dilution workflows to estimate the dilution where ICP reaches 1000, which is then used in HINT setup.
    Default settings:
    • Show Curve Fit: On
    • Blank Correction: On
    • X-axis: Log
    • Fit Function: ICP_robust_logistic3
  • FRNT: Supports FRNT assay data processing and report outputs.
    Default settings:
    • Show Curve Fit: On
    • X-axis: Log
    • Fit Function: logistic4 (V-S-S layouts) or robust_logistic4 (parser-dependent)
    • Blank Correction: parser-dependent; Off for V-S-S Cx5 layouts
    Reference protocol: Current Protocols FRNT method.
Updating Settings

The active setting values and calculated results are shown in the graph/report panel header area (upper-left of the chart view).

Use the Settings page to tune fit behavior, then click Execute to apply changes and refresh Analysis/Report outputs.

Setting Controls
  • Show Curve Fit: Toggles fit-line visibility on analysis charts; disable to inspect only measured data points.
  • Blank Correction: Uses blank/background correction (y_corrected) instead of raw y_values when computing fits and derived labels.
  • Axis Scale: Switches concentration axis between Log and Linear; this affects fit/plot x-series used in charts.
  • Fit Function: Selects the curve model used to compute result labels (for example titer, IC50, ec50, or ICP1000).
  • Execute: Applies all setting changes to the active session and returns to Analysis for immediate review.
Recommended Use By Analysis Type
  • Antigenic tests (HINT/FRNT): Start with X-axis = Log, Show Curve Fit = On, and use robust_logistic4 or logistic4 (parser-dependent defaults).
  • ICP tests: Start with X-axis = Log, Show Curve Fit = On, Blank Correction = On, and use ICP_robust_logistic3.
Model Fits (Code Function -> Supported Parsers)

Default parser-to-fit mappings used on load:

  • anscombe -> linear
  • HINT celigo -> robust_logistic4
  • ICP celigo -> ICP_robust_logistic3
  • FRNT Virus-Serum-Serum Plate Layout Cx5 -> logistic4
  • FRNT Serum-Virus-Virus Plate Layout Cx5 -> logistic4
  • FRNT Virus-Serum-Serum Plate Layout Cytation7 -> logistic4

Fit implementations and parser support:

  • linear -> outlet.functions.linear.LinearRegression -> default for anscombe; selectable for all loaded parsers from Settings.
  • robust_linear -> outlet.functions.linear.RobustLinearRegression -> selectable for all loaded parsers from Settings.
  • logistic3 -> outlet.functions.logistic.Logistic3 -> selectable for all loaded parsers from Settings.
  • robust_logistic3 -> outlet.functions.logistic.RobustLogistic3 -> selectable for all loaded parsers from Settings.
  • ICP_logistic3 -> outlet.functions.logistic.ICP_Logistic3 -> ICP-family option; used with ICP celigo when selected manually.
  • ICP_robust_logistic3 -> outlet.functions.logistic.ICPRobustLogistic3 -> default for ICP celigo; selectable on loaded runs.
  • logistic4 -> outlet.functions.logistic.Logistic4 -> default for FRNT parser labels above; selectable for loaded HINT/FRNT runs.
  • robust_logistic4 -> outlet.functions.logistic.RobustLogistic4 -> default for HINT celigo; selectable for loaded HINT/FRNT runs.
  • logistic4_h=1 -> outlet.functions.logistic.Logistic4_h1 -> selectable for loaded HINT/FRNT/ICP runs.
  • robust_log4_h=1 -> outlet.functions.logistic.Robust_Logistic4_h1 -> selectable for loaded HINT/FRNT/ICP runs.
Reports

The Report page is hidden until data is loaded. After loading, it shows only the report exports that are expected to work for that analysis type.

  • Antigenic/HINT/FRNT-style runs: Antigenic and Result Analysis exports are shown when required result fields are present.
  • ICP runs: ICP 1000 export is shown only when ICP1000 values are available from the active fit results.
  • FRNT pooled-sera runs: FRNT Results export is shown only when pooled-sera metadata and FRNT result fields are available.

If a report link is not shown, that export is not supported for the currently loaded analysis/session.

Supported Instruments
  • HINT:
    • Celigo
  • ICP:
    • Celigo
  • FRNT:
    • Cx5
    • Cytation7

To update settings and re-analyze data: open Settings, change the fit controls, then click Execute to apply updates on the Analysis page. JASPR applies the updated session settings to subsequent chart/table generation and report exports.
