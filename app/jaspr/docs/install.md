Installing jaspr
================

jaspr is designed to be installed on Windows as a standalone package.  It
is provided in two forms.

Install Using `Install jaspr.exe`
---------------------------------

This is a standard single-file executable that will install `jaspr`.
Simply find the file on your computer and double click to install.  A
new `jaspr` folder will be created, containing all of the files needed
to run `jaspr`.  Additionally, an icon will be created on the desktop,
and a menu item will be created under `Start->Programs->jaspr`.

By default, `jaspr` installs to `C:\Program Files\jaspr\`.

Install Using `jaspr.zip`
-------------------------

If installing jaspr using the executable installer is not possible,
a copy of `jaspr.zip` will allow you to install jaspr to any writable
location on the Windows file system.

Locate `jaspr.zip`, and open it (you can double-click the file on any
recent Windows system).  Inside is a `jaspr` folder, which can be copied
to any location on your computer.  You can add a desktop icon for
yourself by going in to the `jaspr` folder and doing
`<right-click>->Create Shortcut` on `jaspr.exe`.  The created icon can
be dragged to the desktop and renamed if needed.

Uninstalling `jaspr`
--------------------

To uninstall a copy of `jaspr` installed using the executable installer,
select `Start->Programs->jaspr->Uninstall jaspr`.  All menu items,
icons, and installed files will be removed.  If any files were added to
the `jaspr` folder after installation, the folder will not be removed
automatically.  If none of the remaining files are needed, the folder
may be removed as well.

To uninstall a copy of `jaspr` installed from a zipped archive, simply
delete all files.
