jaspr Documentation

Description

jaspr is James A. Smagala's Program for Resistance - a simple curve fitting routine designed to automate the analysis of antiviral resistance experiments commonly conducted in the influenza surveillance community. It grew out of frustration over the lack of good analysis software in the CDC Influenza Division. It is designed to do only one analysis, but do it quickly and efficiently.

If you are using 96-well plates to do logarithmic dilutions of reversible inhibitors, jaspr can quickly and easily analyze your data. It now supports more plate layouts. It works best with Perkin Elmer Victor class plate readers, which can read many plates in one run, but can be used with other plate readers with minimal extra work.
